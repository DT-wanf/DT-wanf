# 🚌 SCI-Skills

> 更适合论文小白的科研 Skill 库  
> 上车，带你论文速通。

SCI-Skills 是一个面向科研论文全流程设计的 Skill 系统。

它不会简单地“一键生成整篇论文”，而是根据你的：

- 研究方向
- 已有数据与材料
- 当前论文阶段
- 投稿目标

判断你真正处在哪个研究阶段，并逐步完成：

**选题 → 文献 → 实验 → 分析 → 绘图 → 写作 → 修改 → 投稿**

👉 **项目主页：**
`https://github.com/DT-wanf/SCI-skills`

## 🚀 Quick Start

下载 SCI-Skills 后，将 ZIP 文件发送给你的 Agent：

**Codex / Claude / WorkBuddy 等**

然后输入：

> 帮我安装这个 skill，就安装在这个项目，不要影响其他项目。

即可开始使用。
